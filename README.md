# SVG-drop

Работающее тестовое: веб-редактор, который собирает композиции из исходной векторной библиотеки. В работе используются только объекты предоставленного Figma-файла.

Рабочая версия: https://svgdrop-ochen-test.vercel.app

Материалы к сдаче: [короткая демонстрация](https://svgdrop-ochen-test.vercel.app/submission/03-demo.mp4), [описание архитектуры и AI-инструментов](https://svgdrop-ochen-test.vercel.app/submission/02-solution.pdf), [три SVG-примера с JSON-проектами](examples/).

## Публикация на Vercel


## Запуск

Не нужны npm-пакеты, ключи API или сборка. Из корня проекта:

```sh
python3 -m http.server 5173 --directory dist
```

Открыть http://localhost:5173. Альтернатива: `npm start` с установленным Node.js. Открывать index.html двойным кликом не следует: загрузка модулей и SVG требует HTTP.

## Что реализовано

- Метафора/заголовок → подбор главных объектов по словарю смыслов на русском и английском. Для неизвестной темы явно предлагается базовая пара «книга + цветы».
- Ручное добавление до 50 слоёв во вкладке «Из объектов»: один клик добавляет один предмет. На компьютере предмет можно перетащить из каталога в нужную точку холста.
- Три схемы композиции и их варианты; четыре формата холста.
- Две оригинальные версии детализации S/L, 10 главных и 10 фоновых объектов для каждой версии.
- Три исходные палитры и импорт пользовательской палитры JSON. Семантическая перекраска всех векторов.
- Перемещение мышью/касанием, ширина с сохранением пропорций, поворот, координаты, копирование, удаление, порядок и видимость слоёв.
- Отмена/повтор, клавиатурное перемещение и автосохранение в localStorage.
- Экспорт SVG с отдельными группами и transform; сохранение/открытие редактируемого проекта JSON.
- Три готовых примера в интерфейсе и папке `examples/`.

## Архитектура

`dist/index.html` и `dist/styles.css` — интерфейс. `dist/app.mjs` — состояние редактора, события, история действий, загрузка/сохранение и работа с DOM. `dist/core.mjs` — чистая логика подбора, сборки, палитр и экспорта. `dist/assets/manifest.json` — каталог с ключом, названием, ролью, детализацией, размерами и числом путей. `dist/assets/*.svg` — векторные объекты и фоны. Приложение не требует сервера приложений: статический HTTP-сервер раздаёт файлы, вычисления выполняются в браузере.

Сцена — массив слоёв с `id, key, variant, x, y, w, h, rotation, visible`. Координаты заданы в единицах SVG, независимо от экранного масштаба. История хранит снимки состояния; перетаскивание записывается как одно действие. В проект JSON входят настройки холста, палитра и слои; геометрия берётся из библиотеки.

## Извлечение и повторное использование SVG

Исходник: https://www.figma.com/design/4MCFttsSoP7hgQh29zq5G3/ (тестовое «Иллюстрации»). Для работы создана копия в Drafts. Разделы «Размер L» и «Размер S» экспортированы из Figma как SVG с именами слоёв; эти экспорты сохранены в `assets-source/`.

Скрипт `tools/extract_assets.py` выбирает исходные группы, рассчитывает точные границы кривых Безье и нормализует viewBox. Он не перерисовывает контуры. Для книги L отдельно присоединён исходный путь детали закладки. Получены 40 объектов: 10 предметов × 2 роли × 2 детализации; дополнительно 6 исходных фонов. В коде библиотека логически содержит 20 объектов с двумя вариантами детализации.

Для воспроизведения извлечения (нужно только при изменении источников):

```sh
python3 -m venv .venv
.venv/bin/pip install -r tools/requirements.txt
.venv/bin/python tools/extract_assets.py
```

Пути `d` остаются исходными; позиция нормализуется внешним translate. Объекты помещаются в отдельные SVG-группы. Экспорт формируется из векторов, а не снимка холста. Используются только path/rect/group/clipPath, без bitmap/image, шрифтов и внешних ссылок.

## Сборка и метафоры

Словарь связывает десять предметов с темами: знания, связь, команда, финансы, фокус, идеи, порядок, творчество, покупки, рост. Ранжирование учитывает совпадения с корнями слов и английскими синонимами. До четырёх подходящих объектов получают позиции в выбранном шаблоне; остальные фоновые объекты подбираются из библиотеки. Сохраняются пропорции и исходная перспектива иллюстраций. Результат можно изменить вручную. В ручном режиме дополнительные предметы автоматически не добавляются.

Это намеренно прозрачный алгоритм для ограниченной библиотеки. Он не является универсальным языковым пониманием: сложная метафора может требовать ручного выбора. В runtime нет внешнего LLM и платных API. Подключение LLM можно добавить перед `compose`: модель должна возвращать только ключи уже существующего каталога, затем проходить валидацию.

## Палитра

`background` — три цвета фона/монохромных объектов, `object` — три дополнительных цвета главных объектов. `ink` — контуры, `paper` — белые детали. В фонах используются только background, не object. Геометрия не меняется. Пример JSON:

```json
{"name":"Своя","background":["#D7CDF5","#AA9BF0","#7864D7"],"object":["#F9ECB0","#F9A3AA","#FFE3E1"],"ink":"#181817","paper":"#FFFFFF"}
```

## Проверка

```sh
node --test test.mjs
```

Восемь тестов проверяют смысловой подбор и fallback; полную матрицу активов S/L; границы и пропорции композиций; перекраску без изменения геометрии; экспорт с поворотами, скрытыми слоями, прозрачностью и экранированием заголовка; точный состав ручной композиции; изменение размера повёрнутого объекта с неподвижным противоположным углом; поворот и шаг 15°. Вручную в браузере проверены оба сценария сборки, палитры и их импорт, S/L, форматы, редактирование, копирование, порядок слоёв, undo/redo, скачивание SVG и восстановление проекта. В скачанном контрольном SVG — 487 path и 0 image, сохранён поворот 35°.

## AI-инструменты

При разработке использован OpenAI Codex: анализ условий, написание JS/CSS/Python, подготовка документации и тестов. Figma MCP использован для проверки доступа и создания рабочей сессии; чтение исходников продолжено через браузер из-за лимита Starter. Браузерная автоматизация использована для экспорта исходных SVG и проверки интерфейса. Изображения через AI не генерировались. Смысловой подбор в готовом приложении выполняет описанный словарь.

## Примеры

1. `01-learning.svg` — знания и новые возможности: книга, телефон, пазлы; лаванда.
2. `02-finance.svg` — финансовый рост: кошелёк, монета, цветы; персик.

## Дизайн интерфейса

В редакторе используются локально размещённый Manrope (OFL, лицензия в `dist/assets/fonts/OFL.txt`) и иконки Lucide (ISC, `dist/assets/icons/LICENSE`). На широком экране библиотека и настройки прокручиваются независимо от холста; на ширине до 1100 px доступны разделы «Собрать», «Холст» и «Настройки». Параметры выбранного объекта отображаются в начале панели, клавиатурные вкладки поддерживают стрелки, а фокус на объекте сохраняется после его перемещения.

Маркеры по четырём углам рамки меняют размер с сохранением пропорций; круглый маркер поворачивает объект, Shift включает шаг 15°. При выборе объекта на компьютере над ним появляется панель копирования и удаления; на мобильном она расположена под холстом и не перекрывает маркеры. Каждый жест записывается одним действием в историю. Математика преобразований вынесена в `dist/transforms.mjs`; выпадающие списки с оформленными окнами, Escape и управлением стрелками — в `dist/selects.mjs`.

На мобильном и планшете высота рабочей области рассчитывается по пропорциям выбранного формата; для высокого холста действует ограничение по высоте экрана. Отступы вокруг иллюстрации составляют 12 px на телефоне и 14 px на планшете, без растягивания пустого поля.

На телефоне и планшете под примерами доступна горизонтальная лента десяти объектов. Нажатие добавляет предмет в центр, движение вверх позволяет перетащить его в точку холста; горизонтальный жест листает ленту. Есть кнопки прокрутки, управление стрелками/Home/End и добавление с клавиатуры. Сброс вне холста и отменённый жест не изменяют сцену. Логика ленты вынесена в `dist/object-strip.mjs`.
